How to use this book

What this is

The single source for how StartNet looks and sounds. Where this book and an older file disagree, this book is correct.

It builds on the brand system in the StartNet Website Books (Book 3, Brand Identity) and adopts SNX Red as the primary colour.

What it governs

Anything carrying the name: the website, StartNet X, decks, print, events, signage, social, merchandise and partner material.

It covers all four talent brands: Research, Vibe, Connect and Women. Product interface tokens inherit from here.

When it is silent

Follow the nearest example in the book, and send the work to brand review before it ships.

A new pattern used twice becomes a rule. Write it in here rather than repeating the judgement.
