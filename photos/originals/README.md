# Photo originals

Put StartNet's original photos here as `<slot key>.jpg` (for example `hero/home.jpg` or `event/vibathon/2025.jpg`),
with an optional `<slot key>.json` holding the alt text, caption, focal point and consent. Then run:

```
npm run photos
npm run build
```

The slot keys, crop shapes, the shot list and the consent rules are in [docs/PHOTOS.md](../../docs/PHOTOS.md).
